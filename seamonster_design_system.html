Overview

Introduction

씨몬스터 디자인 시스템은 작업자 간 커뮤니케이션 도구로써 공동 자산을 확장해나갑니다.

PRINCIPLE 01
일관성

동일한 토큰과 컴포넌트를 사용해 어떤 화면에서도 같은 언어로 말합니다.

PRINCIPLE 02
간결함

군더더기 없이, 명확하고 간단하게. 불필요한 장식을 제거하고 본질에 집중합니다.

PRINCIPLE 03
효율성

공통 자산을 재사용해 반복 작업을 줄이고 더 중요한 결정에 집중합니다.

Rules
선의 끝모양과 꺾임은 둥글게 — stroke-linecap: round, stroke-linejoin: round. 씨몬스터의 부드럽고 친근한 톤을 아이콘에도 일관되게 적용합니다.
라인 두께 1.5–2pt — 기본 UI 아이콘은 stroke-width: 1.5를 기본으로 사용합니다. 소형(16px 이하) 또는 강조 용도는 2까지 허용합니다.
Line / Fill 두 가지로 분류 — Line은 비활성·기본 상태에, Fill은 활성·선택·강조 상태에 사용합니다. 같은 아이콘의 두 형태를 혼용하지 않습니다.
크기는 24×24 기준 — 실제 렌더링은 16·20·24·32px 4단계. 아이콘 내부의 optical margin은 2px 여백을 확보합니다.
색상 — 기본은 currentColor로 텍스트 색을 따르고, 강조 시에만 --orange를 적용합니다.

머리와 내장을 제거한 뒤 흐르는 물에 깨끗이 씻어주세요. 키친타월로 물기를 닦으면 비린내를 줄일 수 있습니다. 씨몬스터 제품은 손질 완료 상태로 배송됩니다.
냉동 생선은 어떻게 해동하나요?
냉장실에서 8시간 이상 천천히 해동하는 방법이 가장 좋습니다. 급할 경우 비닐봉지에 넣어 찬물에 30분간 담가두세요. 전자레인지 해동은 식감이 저하될 수 있어 권장하지 않습니다.
배송은 얼마나 걸리나요?
오전 11시 이전 주문 시 당일 출고, 다음날 도착합니다. 일부 지역은 추가 1일이 소요될 수 있습니다.
